# spore — SPR2 wire parser fuzz targets

OSS-Fuzz project integrating the spore E2 wire parsers (frame parse, X3DH
handshake unmarshal, ratchet message unmarshal) as libFuzzer binaries. The
targets live in spore at `internal/wirefuzz`, with their committed seed corpus
under `internal/wirefuzz/testdata/fuzz/seedcorpus/` (generated by
`TestGenerateSeedCorpus`, `SPORE_GEN_SEED_CORPUS=1`).

## Provenance pins

Every change this integration depends on is pinned to the commit it was
verified against. References are checked by `scripts/check_audit_refs.sh`
(see below).

| What | Commit | Enforced where |
|---|---|---|
| Fuzz targets + seed corpus introduced in spore | `25206a2` no-verify-hash | spore repo CI (`audit-refs` job) |
| spore fuzz-smoke matrix targets `internal/wirefuzz` | `8e4af40` no-verify-hash | spore repo CI (`audit-refs` job) |
| Deterministic no-outer-envelope pin in spore | `1542d5c` no-verify-hash | spore repo CI (`audit-refs` job) |
| go-118-fuzz-build tool pin (v1 shim flow) | `a70c2aa677fa43583571959478decabe02a96cd6` no-verify-hash | this Dockerfile (`git checkout` at build time) |
| This integration (project files) | `deeadb9` | this repository's history |

Cross-repo hashes (spore commits, the fuzz-build tool) cannot resolve in this
repository's history, so they carry the `no-verify-hash` marker and are
enforced where they live: spore's own `audit-refs` CI job validates the spore
pins, and the Dockerfile's pinned `git checkout` fails the image build if the
tool pin ever stops resolving. The fork-local pin (`deeadb9`) is checked here.

## Local check

```sh
./scripts/check_audit_refs.sh projects/spore/README.md
```

Extracts backtick-quoted 7–40 char hex refs (lines marked `no-verify-hash`
are exempt) and fails if any does not resolve in this repository. Requires
full history.

## Replaying the build locally

```sh
docker build --tag gcr.io/oss-fuzz/spore \
  --build-arg parent_image=gcr.io/oss-fuzz-base/base-builder-go \
  --file projects/spore/Dockerfile projects/spore
docker run --rm \
  -e FUZZING_ENGINE=libfuzzer -e SANITIZER=address \
  -e ARCHITECTURE=x86_64 -e PROJECT_NAME=spore -e HELPER=True \
  -e FUZZING_LANGUAGE=go \
  -v "$PWD/build-out:/out" -v "$PWD/build-work:/work" \
  -t gcr.io/oss-fuzz/spore
```

Note for Windows hosts (Git Bash/MSYS): `-v` mounts need Windows-style paths
(`$(pwd -W)`), or Docker silently mounts nothing and the build uses the
image's upstream clone instead of a local checkout.
